# Licence de Prax (code d'origine)

Le module `src/prax/` d'Elyndor est un **portage en TypeScript** de Prax,
le moteur de simulation sociale de **ahart (AHartNtkn)** :
<https://github.com/AHartNtkn/Prax> (commit `5e64873`, juillet 2026).

Prax est distribué sous **licence BSD à 3 clauses** (`license: BSD-3-Clause`
dans `prax.cabal` et `rust/Cargo.toml`, auteur déclaré `ahart`). Le dépôt
d'origine ne contient pas de fichier de licence séparé ; le texte standard
de la licence déclarée est reproduit ci-dessous, avec l'auteur déclaré comme
titulaire, conformément à la clause 1 (conservation de la notice dans toute
redistribution du code source) et à la clause 2 (reproduction dans la
documentation de toute forme binaire).

Ce qui vient de Prax : la conception, les algorithmes, les mondes de
démonstration, les messages du vérificateur, les jeux d'essai de
`tests/fixtures/prax/` et les parties de référence utilisées pour la
vérification. Les modifications (portage TypeScript, adaptation à Elyndor,
commentaires en français, outillage de comparaison) sont celles du projet
Elyndor. Les sources tierces que Prax cite (l'article Versu, Praxish, l'article
DEON 2010) ne sont pas redistribuées : Prax lui-même ne les distribue pas.
